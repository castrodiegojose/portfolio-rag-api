# Automatización de Validación de Redes Telecom (Novacor)

## Context

Trabajo como Transport Network Implementation / Radio Access Network Specialist en Novacor (Septiembre 2012 - Enero 2022). Implementación de servicios MPLS para redes de telecomunicaciones (2G, 3G, 4G y 5G).

## Problem

- Validación manual de redes de telecomunicaciones (2G, 3G, 4G, 5G) era lenta y propensa a errores.
- Despliegue, monitoreo y análisis de rendimiento de infraestructura requerían herramientas internas.
- Necesidad de automatizar tareas repetitivas de validación de red.

## Architecture

- **Herramientas de automatización** desarrolladas en Python y JavaScript para validación de redes.
- **Servicios MPLS** implementados para redes de telecomunicaciones.
- **Monitoreo y análisis de rendimiento** de infraestructura de telecomunicaciones.

## My Responsibilities

- Implementar servicios MPLS para redes de telecomunicaciones (2G, 3G, 4G y 5G).
- Desarrollar herramientas de automatización en Python y JavaScript para validación de redes.
- Gestionar el despliegue, monitoreo y análisis de rendimiento de infraestructura de telecomunicaciones.

## Technologies

- Python
- JavaScript
- MPLS
- Redes 2G / 3G / 4G / 5G
- Herramientas de monitoreo de infraestructura

## Technical Challenges

- **Diversidad de tecnologías de red:** 2G, 3G, 4G y 5G, cada una con sus particularidades de validación.
- **Validación manual:** procesos lentos y propensos a errores, resueltos con automatización.
- **Monitoreo y análisis de rendimiento:** visibilidad sobre infraestructura de telecomunicaciones a gran escala.
- **Automatización multi-lenguaje:** Python y JavaScript para cubrir distintas necesidades de validación.

## Results

- Herramientas de automatización en Python y JavaScript para validación de redes.
- Implementación de servicios MPLS en redes 2G, 3G, 4G y 5G.
- Despliegue, monitoreo y análisis de rendimiento de infraestructura de telecomunicaciones gestionados.
- Reducción del esfuerzo manual en validación de redes.

## Que no hice

- **Desarrollo de backend, APIs ni microservicios.** No construí servicios REST, GraphQL ni arquitecturas de microservicios. Eso corresponde a roles posteriores (OpenDev Pro, Singular Agency, BDG).
- **Cloud (AWS, GCP), Docker ni Kubernetes.** No trabajé con proveedores cloud, containerización ni orquestación. El despliegue era sobre infraestructura de red de telecomunicaciones, no sobre servicios cloud.
- **Mensajería asíncrona ni arquitecturas orientadas a eventos.** No usé Kafka, RabbitMQ ni sistemas event-driven. Esa experiencia viene de roles posteriores.
- **Bases de datos relacionales o NoSQL.** No trabajé con PostgreSQL, MongoDB ni MySQL en este rol. La automatización era sobre red y configuración, no sobre persistencia de datos de aplicación.
- **Desarrollo frontend, web ni mobile.** No construí interfaces de usuario, dashboards ni aplicaciones web.
- **Liderazgo de equipos ni gestión de personas.** No tuve rol de tech lead, manager ni coordinación de equipos de desarrollo.
- **IA, machine learning ni integración con LLMs.** No trabajé con modelos de IA, Prompt Engineering ni automatización basada en IA.
- **Integraciones de pago (Stripe, etc.) ni sistemas de checkout.** Fuera del alcance de este rol.
